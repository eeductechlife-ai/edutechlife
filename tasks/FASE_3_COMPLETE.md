## Lessons Learned

✅ **What worked:**
- Database triggers maintaining consistency (no app-side logic needed)
- React Query cache invalidation (proper cache keys prevent stale data)
- RLS policies as first-class security (prevents IDOR at DB level)
- Code review catching critical bugs (IDOR, race condition, path typo)

⚠️ **What was hard:**
- StrictMode double-mount (needed ref guard, not obvious)
- Upsert dedup on composite keys (easy to misconfig)
- Trigger latency (1-3s acceptable for analytics, not ideal for real-time)
- Testing DB-backed features (need service_role key, complex setup)
