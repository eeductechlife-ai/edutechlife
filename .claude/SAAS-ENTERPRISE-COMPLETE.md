## 🚀 CÓMO USAR EL EQUIPO

### **Spawn All Agents at Once**
```javascript
// spawn-team.mjs - Ejecuta una sola vez para iniciar el equipo
import { Agent } from "@anthropic-ai/sdk";

const agents = [
  {
    name: "architect",
    subagent_type: "architecture",
    prompt: "Eres el Architect..."
  },
  {
    name: "backend-dev",
    subagent_type: "agent-skills:code-reviewer",
    prompt: "Eres Backend Engineer..."
  },
  // ... resto de agentes
];

agents.forEach(agent => {
  Agent({
    ...agent,
    run_in_background: true
  });
});

console.log("✅ Equipo activado!");
```
