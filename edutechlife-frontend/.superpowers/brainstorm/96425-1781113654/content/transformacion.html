Transformación Técnica (en detalle)

El núcleo del enfoque C es convertir rangos (offset start/end) en elementos <mark> dentro del HTML

Algoritmo de transformación

1. Recibir: rawHTML + highlights[{startOffset, endOffset, color}]
2. Extraer texto plano del HTML (eliminar etiquetas)
3. Para cada highlight:
   - Calcular offset en el texto plano
   - Mapear offset de texto plano → offset en HTML con etiquetas
4. Insertar <mark> en las posiciones correctas del HTML
5. Devolver HTML transformado con highlights visibles

Ejemplo concreto

HTML original
<p>El <strong>aprendizaje profundo</strong> permite...</p>
Texto plano
El aprendizaje profundo permite... ↑highlight desde offset 3 hasta 23
HTML transformado
El <mark>aprendizaje profundo</mark> permite...

Persistencia

Guarda

  • resourceId
  • startOffset (texto plano)
  • endOffset (texto plano)
  • color — #FFEB3B por defecto
  • createdAt — timestamp ISO

No guarda

  • Fragmentos del HTML original
  • Información de nodo DOM
  • Clases CSS o estilos

Los offsets en texto plano son estables incluso si el HTML cambia de formato

Edge Cases cubiertos

✅ Highlights solapados

✅ Texto con etiquetas HTML anidadas

✅ HTML sin texto (imágenes, iframes)

✅ Múltiples highlights en un párrafo
