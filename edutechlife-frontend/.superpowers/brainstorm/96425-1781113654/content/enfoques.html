3 Enfoques para Anotaciones Inline

Selecciona el que prefieras

A

Hook + Componentes Independientes

useAnnotations.js — hook que maneja selección, highlights, persistencia

AnnotationLayer.jsx — overlay que se posiciona sobre el contenido

FloatingToolbar.jsx — menú flotante al seleccionar texto

  • 100% aditivo
  • Fácil de testear
  • Desacoplado
  • Requiere wrapper en resource viewer
B

Sistema Overlay Global

Intercepta selección en cualquier parte del resource viewer

Guarda highlights como rangos serializados (offset start/end)

Renderiza highlights como elementos posicionados absolutamente

  • Funciona con cualquier contenido
  • Sin modificar viewers
  • Serialización de rangos frágil
  • Más complejo de mantener
C

Transformación de Contenido

Procesa el HTML del recurso al cargarlo

Inyecta spans de highlight directamente en el markup

Re-renderiza al añadir/quitar highlights

  • Más simple conceptualmente
  • Flujo DOM natural
  • Acoplado al contenido
  • Re-renderiza completo en cada cambio
